## Структура
- `index.html` — навігаційна сторінка лабораторної.
- `task-1.html` — форматування тексту (рецепт млинців із сиром).
- `task-2.html` — резюме із семантичними областями HTML5.
- `task-3/index.html`, `page1.html`, `page2.html` — три взаємопов'язані сторінки з посиланнями та зображеннями.
- `task-4.html` — хімічні та математичні формули з `sub` і `sup`.
- `task-5.html` — блог новин із навігацією, статтями та бічною панеллю.
- `style.css` — спільне адаптивне оформлення.

Відкрийте `index.html` у браузері. Для перевірки HTML завантажте кожен файл на https://validator.w3.org/ (File Upload).
