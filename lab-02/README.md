## Структура
- `index.html` — навігаційна сторінка лабораторної.
- `task-1.html` — форматування тексту на прикладі рецепта.
- `task-2.html` — резюме із семантичними областями HTML5.
- `task-3/index.html`, `page1.html`, `page2.html` — три взаємопов'язані сторінки з гіперпосиланнями на зображення.
- `formulas.html` — хімічні та математичні формули з `sub` і `sup`.
- `blog.html` — блог новин із семантичними тегами HTML5.

Відкрийте `index.html` у браузері. Для валідації завантажте `blog.html` на https://validator.w3.org/#validate_by_upload.

Сторінки виконані засобами HTML5 без CSS, відповідно до вимог лабораторної роботи.
